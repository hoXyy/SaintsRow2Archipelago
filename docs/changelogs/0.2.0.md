# New features
- New locations:
    - Style Level (Lvl 1 to 10)
        - the amount of levels added to the seed is configurable in the settings

# Fixes
- the item `Vehicle: Saints Oppressor` now correctly unlocks the correct vehicle instead of unlocking the Horizon (Medical Helicopter)
- vehicle tricks (like Near Miss or Opposite Lane) now trigger correctly, which makes later Escort levels possible again
    - this fix will make the game show as if you're respect from some of the vehicle tricks, this is purely a visual thing
- the notoriety traps now trigger properly if the player already had notoriety from a gang (for gang notoriety traps) or the police (for police notoriety trap)

# Misc. changes
- the config file is now a TOML file instead of an INI file
    - if you did any changes to the config file you'll need to move them to the new format
- rearranged the settings groups a bit, and changed the display name for some of the settings
- did some refactoring in the game integration plugin
