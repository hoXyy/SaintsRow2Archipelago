# New features

- **New locations**:
    - Stunt Jumps (80* checks)
        - the stunt jump that's intended to be done at the end of `Pyramid Scheme` isn't added to the location list if the Ultor Arc isn't enabled
    - Diversions (10 checks each)
        - Taxi Driver
        - Ambulance EMT
        - Tow Truck
        - Fire Truck
        - Ho-ing
    - Stunt Jumps and each Diversion have new items to unlock them
- The mission `Revelation` and the `Stilwater Caverns Stronghold` now have unique items to unlock them:
    - `Dex's Phone Number` for Revelation
    - `Stilwater Caverns Stronghold Unlock` for the Stilwater Caverns stronghold
    - due to this both missions no longer require a bar of respect to start
- Added consumable filler items (food, booze, etc.)
- Added support for Deathlink
- Added a version number and client connection status to the bottom left of the main menu and the pause menu
- Added an in-game AP notification log which shows:
    - Sent/Received items
    - Deathlink messages
- The whole map is now unfogged from the start of the game to allow for easier taxi fast travel at the start of the game
- When opening a Chop Shop or Hitman list for the first time, hints are sent out for locations within that list
- Added an option to use progressive collectible locations instead of individual ones
    - you can use the options to limit how many progressive collectible locations you want to have per collectible type
- Added an option to select how many levels of each activity type you want to have in your seed
- Added an option to toggle races by vehicle class instead of just being able to toggle races overall

# Changes
- Changed the `+1 Respect` item classification from `progression` to `progression_skip_balancing`
    - this is a bit of an experimental change to see how it plays, if it's bad or just different I might add an option to toggle this change in the next update
- Renamed a lot of filler items in the goal of removing prefixes from them:
    - For example: `Weapon: Pimp Slap` -> `Pimp Slap`
    - Some items have an extra suffix to make it easier to see what it actually is, for example `Five-O (Cop Car)`
- Reworked weather items - they no longer set the weather to be fixed until another weather item comes along:
    - 2 items got removed due to this:
        - `Restore Normal Weather Cycle` - not useful anymore
        - `Thunderstorm` - with the reworked weather item handling it was the same as `Heavy Rain`, no point having 2 items that do the same thing
- Rearranged how options are grouped

# Fixes
- Fixed an issue where an early goal would be sent if other players collected items from locations that are your goal locations (most possible for this to happen on a single-arc seed, as it only required the item from one location to be collected)
- Selecting an optional location as required to goal now automatically adds it to the location list without needing to enable the extra option to include it manually
- Fixed some edge cases regarding item delivery
