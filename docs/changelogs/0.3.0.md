# New features

- **New locations**:
    - Tags (50 checks)
- **Reworked progression**
    - The following content now requires an item to access:
        - Activities
        - Races
            - These are split by vehicle class: Car, Plane, Boat/Jetski, Heli, Bike
        - Collectibles (Tags and CDs, each have a separate item)
    - In the options you can select which activity you want to start with, and you'll receive the item to unlock it after finishing Appointed Defender
- **Ultor Epilogue is now Ultor Arc**
    - The Ultor mission chain has been turned into another gang arc that you can enable that will unlock after completing Three Kings
    - This allows for creation of shorter seeds as it can now be played standalone without any other arcs
- **Stilwater Caverns Stronghold is now an optional location**
    - As with the Ultor Revelation mission, you can enable an option to require it as part of the completion goal
- **Reworked how weapon and money filler items work**
    - This should fix the multiple softlocks that happened in activities like Heli Assault or Septic Avenger when receiving a weapon during them
- **Universal Tracker support, with support for UT's map tracker**
    - The tracker now takes into account how much respect is acquired and the amount of missions completed when calculating what's in logic
    - For the map tracker I recommend using the newly released v0.3.4 of UT, as it allows zooming in on the map
- **New items**:
    - `Weapon: Minigun`
    - `Weapon: Flamethrower`
    - `$25,000`
    - `$50,000`
    - `$100,000`
- **Added an option to disable specific trap item type**
    - Now you can disable either the weather trap items or the notoriety trap items (or both!)
- **Rebalanced Style Level locations**
    - As Style Level 8 and upwards require a lot of money to reach, by default there cannot be progression items on those locations (with an option to allow putting progression items there)
    - The options now default to including up to Style Level 7 instead of Style Level 10
- **Added an option to set weights of filler item categories when generating a world**
    - The option is split between the following filler item types:
        - Money
        - Weapon
        - Vehicle
        - Misc.

# Fixes
- Fixed multiple **major** issues that would happen when playing in an async session such as:
    - Goal not registering properly
    - List of received items not being saved properly
- (Hopefully) fixed the respect bar showing infinity when not even close to hitting 99x Respect bars
- Fixed an edgecase when using the Start Inventory option to add an item that wasn't in the generated item pool which would cause that item to be rejected and stop item delivery completely
- Fixed vehicle drifting not registering in later Escort levels

# Other changes
- Major refactoring to the game plugin to make it even easier for me to add new things to it
    - I've tested as much of it as possible and nothing broke, but if something is broken please let me know
- Ultimate ASI Loader is now included with the release zip file for easier installation
- As an alternative to the UT map tracker, high-res collectible maps that were used to number the APWorld locations are included in the release
